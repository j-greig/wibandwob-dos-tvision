# --- pyramid-equals (textured slope) ★ STANDOUT ★
# Source: ascii.co.uk/art/pyramid — unsigned, no artist sig (unlike jjs/tre/KCK/ejm97)
# Why: the `=` fill texture reads like screen-print ink density; the floating `'` tick-marks
# on the right slope are the key move — they suggest sand, grain, light scatter, NOT outline.
# That trick (sparse tick-marks as surface texture rather than edge-drawing) is directly
# useful for the fair: gives a printed surface feel without closing the shape.
               '
              /=\
             /===\ \
            /=====\' \
           /=======\'' \
          /=========\ ' '\
         /===========\''   \
        /=============\ ' '  \
       /===============\   ''  \
      /=================\' ' ' ' \
     /===================\' ' '  ' \
    /=====================\' '   ' ' \
   /=======================\  '   ' /
  /=========================\   ' /
 /===========================\'  /
/=============================\/
